---
name: dry-lists
description: Derive smaller lists or sets from an existing source collection without duplicating its contents. Use when defining a subset of an existing list or set.
---

When needing a list or set with fewer items, reference the source collection and filter out the items not needed. Do not copy the source items into a second collection.

Keep the source collection as the single place where shared membership is maintained. Express the subset through exclusions, using the language's filtering or set-difference operation.
